## Мои проекты

### [MonitoringProdEquipments](https://github.com/Lamer002/MonitoringProdEquipments) — C++ / Qt

Приложение для наблюдения за виртуальными производственными станками. Показывает температуру, обороты и состояние оборудования, реагирует на перегрев и сохраняет журнал событий в SQLite. Для проекта настроены сборка через CMake и базовые автоматические тесты.

### [FinanceWallet](https://github.com/Lamer002/FinanceWallet) — C# / WPF

Учебное приложение для учёта доходов и расходов. Работа с транзакциями, категориями и балансом через Entity Framework Core и PostgreSQL. Отдельно пробую ASP.NET Core Web API — эта часть пока в разработке.

### [Planet Earth with Qt](https://github.com/Lamer002/Planet_Earth_With_Qt) — C++ / Qt

Небольшой графический проект с анимацией Земли. Практиковался с QPainter, таймером, слоями и прозрачностью.

### [Inventory Team](https://github.com/Lamer002/Inventory_Team) — C# / WPF

Учебная система учёта оборудования по кабинетам. Добавление и перемещение техники, поиск, фильтры и история операций. Использованы WPF, Entity Framework и SQL Server.
